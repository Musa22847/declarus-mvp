# Декларус — OCR MVP упаковочных листов

Локальный Streamlit-сервис: загрузка одного упаковочного листа, распознавание
через Yandex Vision OCR, извлечение данных через Qwen и скачивание Excel.
Задания выполняет отдельный последовательный worker; состояние хранится в SQLite.

## Запуск

1. Установите и запустите Docker Desktop.
2. Скопируйте `.env.example` в `.env` и заполните `YANDEX_FOLDER_ID` и `YANDEX_API_KEY`.
3. Из корня проекта выполните:

```sh
docker compose up --build -d
```

Откройте <http://localhost:8501>. Поддерживаются PDF, JPG, JPEG, PNG и WebP,
до 10 МБ на файл и до 10 страниц. Для обращения к Yandex нужен интернет;
обработка использует платные API вашего облачного аккаунта.

```sh
docker compose ps
docker compose logs --tail 50 worker
docker compose stop
```

## Данные и восстановление

Результаты JSON/XLSX, оригиналы документов и база заданий находятся в `ui/output`.
Папка подключена к обоим контейнерам и сохраняется при их пересоздании.
Задание восстанавливается по `job_id` в URL или открывается через историю.
Подробности: [README-jobs.md](README-jobs.md).

В Excel выводятся данные исходных документов. `declaration_draft`, исходный текст
и координаты сохраняются во внутреннем JSON. По умолчанию детализация и исходный
текст исключены из Excel; настройки экспорта перечислены в `.env.example`.

## Состав проекта

- `ui/streamlit_app.py` — интерфейс.
- `ui/job_store.py` — задания и SQLite.
- `ui/worker.py` — последовательная обработка и восстановление.
- `mvp/ocr_table_pipeline.py` — обращения к Vision OCR и Qwen.
- `mvp/xlsx_export.py` — формирование Excel.
- `mvp/system-prompt/` — инструкции модели.
- `mvp/documents/few-shot_raw/` и `few-shot_labelled/` — обязательные эталонные пары.

## Секреты

Настоящий `.env`, документы тестировщиков, история, SQLite и служебные файлы
исключены из Git и Docker build context. В репозитории публикуется только пустой
шаблон настроек. Не вставляйте ключи в код, промпты, скриншоты или сообщения Git.

История в этом локальном MVP общая. Авторизация и разделение данных пользователей
пока не реализованы.
